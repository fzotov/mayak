# Выгрузка взаиморасчётов из 1С для Маяка: доработка (v2)

Для: программиста 1С (Бухгалтерия предприятия 3.0, HTTP-сервис `o.mayak-d.ru/export/debts.xml`).
Зачем: перенести остатки расчётов с арендаторами в Маяк на дату перехода и сверить их до копейки (ТЗ v2, этап 3).

## 1. Что сейчас не так

1. С 23.11.2026 запрос `GET https://o.mayak-d.ru/export/debts.xml` (заголовок `X-Auth-Token`) отвечает **504 Gateway Timeout** через 30 секунд: веб-сервер перед 1С не дожидается, пока сформируется ответ.
2. В открытых документах нет строк номенклатуры. Поэтому долг по акту нельзя разбить на аренду, коммунальные, уборку и рекламу: сейчас он весь попадает в статью «Входящий остаток из 1С без разбивки».
3. Нет номера, даты и вида договора отдельными полями. Сейчас они вытаскиваются из наименования, и у 19 из 110 договоров не находятся (например «Основной договор»).
4. Нет обеспечительных платежей (депозитов), полученных по договорам.

## 2. Что сделать

### 2.1. Таймаут

Любой из вариантов:
- формировать файл регламентным заданием (например, раз в час и по запросу) и отдавать готовый;
- или увеличить таймаут прокси (`proxy_read_timeout` в nginx или аналог) до 120 секунд и ускорить запрос.

Ответ должен приходить за 50 секунд или быстрее: столько ждёт Маяк.

### 2.2. Параметр даты

`GET /export/debts.xml?asOf=YYYY-MM-DD` — остатки **на конец дня** `asOf`. Без параметра — на текущую дату, как сейчас. Значение пишется в атрибут `asOf` корня.

### 2.3. Формат v2

Обратно совместим: старые атрибуты и элементы остаются, добавляются новые. Кодировка UTF-8, суммы с точкой, две цифры после точки, даты `YYYY-MM-DD`.

```xml
<Debts version="2" generated="2026-12-01T09:00:00" asOf="2026-11-30" operationsFrom="2026-01-01" org="ИП Зотова Е.В." orgInn="500705271772">
  <Counterparty id="GUID" name="ООО Ромашка" inn="7700000000" kpp="770001001" debt="12000.00" advance="0.00" deposit="20500.00">
    <Contract id="GUID" name="Договор аренды № 13/2026 от 22.06.2026"
              number="13/2026" date="2026-06-22" kind="rent"
              debt="12000.00" advance="0.00" deposit="20500.00">
      <Doc id="GUID" type="Реализация (акты, накладные, УПД)" number="00ИП-000948" date="2026-11-30" account="62.01" debt="12000.00" advance="0.00">
        <Line item="Аренда помещения 204" itemCode="00-000001" account="62.01" amount="10000.00"/>
        <Line item="Электроэнергия" itemCode="00-000007" account="62.01" amount="1500.00"/>
        <Line item="Уборка" itemCode="00-000009" account="62.01" amount="500.00"/>
      </Doc>
      <Doc id="GUID" type="Поступление на расчетный счет" number="123" date="2026-11-28" account="62.02" debt="0.00" advance="3000.00"/>
    </Contract>
    <Op .../>   <!-- история операций — как сейчас, без изменений -->
  </Counterparty>
</Debts>
```

| Где | Атрибут | Что |
|---|---|---|
| Debts | `version` | `2` |
| Counterparty, Contract | `deposit` | Остаток полученного обеспечительного платежа на `asOf` (кредит счёта учёта депозитов, см. п. 3). Ноль, если нет |
| Contract | `number`, `date` | Номер и дата договора из реквизитов договора, а не из наименования |
| Contract | `kind` | `rent` (аренда), `ad` (реклама), `deposit` (обеспечительный), `service`, `other` |
| Doc | `account` | Счёт учёта расчётов по документу (62.01, 62.02, 76.xx) |
| Line | `item`, `itemCode`, `account`, `amount` | Строки табличной части документа реализации: номенклатура (наименование и код), счёт учёта, сумма строки с НДС. Только для документов с непогашенным долгом |

**Важно.** Сумма строк — это сумма документа. Непогашенный остаток `debt` может быть меньше. Маяк делит остаток пропорционально строкам: копейки округления уходят на последнюю строку.

## 3. Вопросы бухгалтеру

1. На каком счёте учитываются обеспечительные платежи арендаторов (76.06? 62.02 по отдельному договору?) и как их отличить в выгрузке.
2. Дата перехода. По умолчанию это 1-е число месяца после приёмки этапа 4 (банк). После неё начисления ведёт Маяк, а в 1С они загружаются из Маяка.
3. Список номенклатуры 1С для арендаторов и соответствие статьям Маяка:

| Статья Маяка | Номенклатура 1С | Счёт учёта |
|---|---|---|
| Аренда, коммунальные (электроэнергия, вода, тепло, вывоз мусора), уборка, разовые услуги, реклама на стеле, прочая реклама, пени, штрафы | | |

   Оно же нужно для обратной выгрузки «Маяк → 1С».
4. В каком виде 1С принимает реализации (акты) из Маяка: EnterpriseData (универсальный формат обмена, «Загрузка данных из файла») или другой. Нужен один тестовый документ, который загрузится без ручной правки.
5. Нужно ли передавать в 1С поступления, или они идут из банка напрямую в 1С.

## 4. Как Маяк это использует

- «Ещё → Переход с 1С» → «Загрузить из 1С» (или файл `debts.xml`): контрагенты сопоставляются с арендаторами по `id_1c`, затем по ИНН, без автосоздания; договоры — по номеру.
- Остатки разбиваются по статьям правилами «номенклатура / счёт / договор → статья», которые можно менять на экране «Остатки».
- Сверка «сальдо Маяка = сальдо 1С» по каждому арендатору, отдельно расчёты и отдельно депозиты, с актом сверки.
- Проведение на дату перехода. Ошибку исправляют сторно и повторной загрузкой.
- После перехода: раз в месяц контрольная сверка с той же выгрузкой.
