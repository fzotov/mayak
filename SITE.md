# Структура проекта

| Что | Где | Адрес |
|-----|-----|-------|
| Публичный сайт mayak-d.ru | `apps/site` (Next.js) | `/` |
| Система управления зданием | `src/App.tsx` + `src/pages` (Vite) | `/admin` |
| Личный кабинет арендатора | `src/TenantApp.tsx` + `src/pages/tenant` (Vite) | `/tenant` |

Сайт и внутренние разделы — разные приложения с общей базой Supabase.
Сайт деплоится отдельным проектом Vercel с корнем `apps/site`, внутренние разделы — текущим проектом.
Ссылка «Личный кабинет арендатора» с сайта ведёт на `/tenant`.

Запуск:

```bash
pnpm --dir apps/site dev   # сайт, http://localhost:3000
pnpm dev                   # админка и кабинет, http://localhost:5173
```

## Заявки с сайта

Форма сайта пишет в таблицу `site_leads` Supabase, заявки видны в админке в разделе
«Сайт и заявки». Таблица и бакет для фотографий создаются миграцией
`supabase/migrations/20260920_site.sql` — её нужно один раз выполнить в SQL-редакторе Supabase.

## Помещения

Каталог помещений сайта живёт в `apps/site/data/offices.ts`, схемы этажей — в `apps/site/data/floors.ts`.
Раздел админки «Сайт и заявки» управляет теми же помещениями в таблице `units`;
чтобы сайт брал статусы и фотографии оттуда, достаточно поменять реализацию `apps/site/lib/offices.ts` —
компоненты сайта от источника данных не зависят.
